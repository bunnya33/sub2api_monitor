## v0.4.1 托盘菜单修复

- 移除浮球右键菜单及对应的渲染进程命令；设置、刷新、更新等操作统一从托盘进入。托盘菜单窗口独立缓存，按图标边界定位，并允许覆盖任务栏区域。

- 类型检查、28 项单元测试、构建及 0.4.1 打包版桌面测试通过，报告为 `artifacts/electron-v0.4.1-packaged-smoke/result.json`。验证覆盖浮球右键无菜单、首次单次显示、非激活失焦通知、重复右键、更新确认复位和模拟系统面板的焦点保持；真实 Windows 托盘溢出面板仍需实机验收。
- 安装包、blockmap、`latest.yml` 和免安装版保存在 `release/v0.4.1/`。清单的文件名、大小和 SHA-512 已核对，免安装版与桌面测试使用的程序一致；安装包未签名。

## 当前主线：Electron

- 当前渲染层为 Vue 3 + Element Plus + TypeScript，桌面功能由 Electron 提供；WPF 实现保留在当前仓库，并加标签 `wpf-baseline` 指向 `ee75647`。
- 设置中的二元选项改为带动画的 Element Plus Switch，选择、数字、滑块、颜色和输入控件统一使用 Element Plus。安装版 Windows 开机自启动默认开启，可在「刷新」页关闭；自动化测试使用隔离数据目录，不修改系统启动项。
- 实现透明置顶浮球、整块区域拖动、四边吸附、贴边账号轮播、悬停明细和失焦透明度。
- 拖动进入吸附范围时显示不接收鼠标输入的贴边形态预览，松手后正式吸附；失焦透明度滑块支持连续拖动并在松手后保存。
- 实现自绘托盘右键菜单及自绘五页设置，浮球右键菜单已移除。账号页支持本地别名；样式页支持名称、进度条与贴边宽度。
- 托盘菜单使用 `pop-up-menu` 层级，在渲染就绪后以非激活方式打开；透明点击层只覆盖当前屏幕的可用工作区。桌面外部点击先关闭菜单并保持原面板焦点，真实“更多图标”面板的层级和焦点仍需实机验收。
- 「样式」页支持三色预览、字号、粗细与 TTF 导入；本地字体协议只读取固定的用户字体文件。
- 字号和粗细只作用于浮球及设置中的预览，设置页保持固定排版；进度条文字按背景色计算同色系文字并满足至少 4.5:1 对比度，可在「样式」中开启从文字色压暗得到的 0.5 px 描边，默认关闭。
- 移除固定详情功能和按钮；托盘打开菜单时关闭额度详情。
- 进度条内增加 `5h` / `7d` 标记；显示页新增 7 天开关，并根据 sub2api 脱敏账号档位在 Pro、5x/20x 和 Max 等账号上隐藏 5 小时进度，浮球宽度随可见周期变化。
- 周期标签贴齐进度条左上角；5h 使用 sub2api 的 indigo-100 / indigo-700，7d 使用 emerald-100 / emerald-700 配色，最窄 40 px 进度条仍能完整显示百分比。
- 详情移除关闭按钮、账号源数据时间和本次读取时间；新增订阅类型、订阅到期时间、可用重置次数及最近重置卡到期时间，并移除账号区来源文案。“显示”页提供两个独立的重置信息开关，详情高度跟随可见字段调整。
- 订阅到期移到会员类型后；进度条右下角显示每秒更新的重置倒计时，移除条上方的 5 小时/7 天标题及条下方的重置文案。重置卡改用最近一张未过期卡的到期时间；没有卡时显示“无重置卡”并隐藏时间。账号状态默认只读，“显示”页开启状态开关后，管理员可在详情切换可用/停用状态；错误状态与演示数据保持只读。
- 详情在屏幕角落优先避开浮球；样式页的五种宽度只限制为正整数，并增加重置倒计时字号。贴边摘要支持单独 5h、单独 7d 或按账号轮播 5h/7d，Pro 账号回退到 7d。显示页可启用每账号一张独立并发卡片，默认宽度由 48 调整到 36 DIP，样式页可另行调整；顶部和底部贴边默认宽度由 178 调整到 160 DIP。并发数据读取 sub2api 0.2.8 管理员账号列表的 `current_concurrency`/`concurrency`。倒计时移除前导零，分钟段不显示秒，不足一分钟时才按秒更新。
- 并发卡片采用 sub2api 的空闲灰、使用中黄、满载红三档浅底深字配色；并发大于 0 即以黄色提示正在使用，达到正数上限时转为红色。
- 核对 v0.2.8 的 OpenAI OAuth `/quota` 接口，重置次数与最近重置卡到期读取服务端 `available_count`、`credits[].expires_at`；缺失数据为 `--`，查询失败保留旧值并提示错误。每轮重新读取账号订阅和并发信息，订阅到期与令牌到期严格区分。
- 进度条已对齐 sub2api `UsageProgressBar.vue`：已用 75%/90%、剩余 50%/20% 分级，默认使用 Tailwind green/amber/red-500；旧版默认配色自动迁移，自定义颜色保留。
- sub2api 0.2.8 登录、2FA、管理员校验、账号读取、额度刷新及 Windows `safeStorage` 加密会话已实现。
- `npm run typecheck`、`npm test`、`npm run build` 通过，Vitest 26 项测试通过；独立目录的 Electron Windows 打包成功。
- Playwright 真实 Electron 窗口验证包括进度条与名称拖动、悬停明细自动收起、透明度滑块连续拖动、字号作用范围、拖动中的吸附预览、贴边与轮播，以及本地模拟服务器的邮箱密码、2FA、管理员和额度流程。
- `release/corner-tags-build/win-unpacked/Sub2API Quota Monitor.exe` 的打包版本也通过同一套窗口与字体验证。
- 上一打包目录为 `release/account-details-build/win-unpacked/`；重置信息开关、订阅、缺失字段、重启后的配置恢复均已加入桌面验证。
- 上一安装包为 `release/v0.2.4/Sub2API Quota Monitor Setup 0.2.4.exe`，同目录的免安装程序通过完整 Electron 窗口测试，覆盖右下角详情避让、最小宽度输入、贴边周期回退/轮播、36 DIP 并发卡片及三档颜色、旧配置迁移、倒计时字号、托盘菜单工作区边界的模拟面板和重启持久化。安装包未签名。
