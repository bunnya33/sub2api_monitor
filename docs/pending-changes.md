# 更新记录与待发布修改

本次发行版本：v0.4.6。用户已明确要求发布，以下为核对后的发行内容。

发布约定：只有用户明确要求发布热更新时，才先核对并说明本页内容，然后打包、上传与正式发布。日常修改只完成本地开发与验证。
