# Sub2API Quota Monitor：Electron 方案

日期：2026-09-28。平台：Windows 10/11 x64。服务器接口：sub2api 0.2.8。原 WPF 实现在同仓库保留，基线标签 `wpf-baseline`。

## 窗口与显示器

采用 Electron `BrowserWindow` + Vue 3/CSS，设置控件使用 Element Plus。浮球和悬停明细是透明、无系统边框、置顶且不主动获取焦点的窗口；设置和右键菜单也是自绘窗口。系统托盘仍由 Electron 原生 `Tray` 承载，右键时按图标边界在附近显示自绘菜单。浮球右键不弹菜单；设置、刷新、更新与退出统一使用托盘菜单。菜单每次打开创建独立窗口，关闭时释放，避免非激活窗口沿用上次点击后的输入状态；加载期间的重复请求会合并，旧窗口的关闭回调不会影响新窗口。

Electron 的 `screen` 工作区、鼠标位置及 `BrowserWindow` 边界统一使用逻辑像素（DIP）。拖动过程中读取当前指针位置，松开时以目标显示器的 `workArea` 计算四边吸附，避开任务栏；显示器增删与工作区变化时重新限制位置。支持负坐标和每屏独立缩放。已有的两屏同为 100% 缩放，混合 DPI 仍需实机验证。

整块浮球监听指针事件，账号名和进度条都可开始拖动。主进程使用系统指针坐标更新窗口，渲染器的指针坐标作为自动化和异常情况下的补充。拖动移动通过完整 `setBounds` 指定开始拖动时的逻辑宽高，避免 `setPosition` 在 175% 等非整数缩放下重复复用已舍入的原生尺寸并逐渐增大。位置没有变化时不再提交窗口更新。悬停、拖动和查看明细期间暂停贴边账号轮播。
拖动进入四边吸附范围时，在目标工作区边缘显示实际贴合尺寸的摘要预览；预览窗口不接收鼠标输入，松手后浮球才正式吸附。

## 浮球与明细

- 每账号一行：显示名称、5 小时条、7 天条；条内左上角以 `5h` / `7d` 标明周期，标签贴齐左侧和顶部，右下角小圆角。配色与 sub2api 浅色模式一致：5h 为 indigo-100 / indigo-700，7d 为 emerald-100 / emerald-700。默认两账号尺寸 224 × 64 DIP。
- `5 小时` 和 `7 天` 可分别在设置隐藏；只有一个周期显示时，默认名称宽度下两账号尺寸变为 150 × 64 DIP。悬停明细仍显示可用周期。
- 从 sub2api 0.2.8 账号列表的脱敏 `credentials.plan_type`（影子账号使用 `parent_plan_type`）判断订阅档位：Plus 显示 5 小时；明确的 Pro、5x/20x、Max 和更高档位不显示 5 小时。档位缺失时保留服务端提供的 5 小时数据，避免误隐藏。
- 显示名称优先使用用户别名，未设置时用服务器名称。别名只影响本地展示，不修改 sub2api 账号。
- 设置的“账号”页显示可用重置次数；有次数时显示重置按钮，通过 Element Plus Popconfirm 确认账号及消耗 1 次重置机会后才执行。影子账号需在母账号操作。执行期间禁用按钮，完成后同步次数与额度，结果未确认时提示先刷新。
- 名称、进度条、顶部/底部摘要及两侧摘要的宽度在“样式”页设置，允许任意正整数 DIP；超长文本截断并保留完整名称提示。
- 百分比默认表示已用，也可选择剩余；进度条长度与颜色按当前显示的含义计算。进度条内显示百分比，缺失数据为 `--`。
- 对齐 sub2api `UsageProgressBar.vue`：已用 <75% 正常、75%–89% 注意、≥90% 接近耗尽；剩余 >50% 正常、21%–50% 注意、≤20% 接近耗尽。默认颜色分别为 Tailwind `green-500` (`#22c55e`)、`amber-500` (`#f59e0b`)、`red-500` (`#ef4444`)；三色均可修改并预览。旧版默认配色在读取配置时迁移，自定义配色保留。
- 百分比文字由当前进度色计算同色系深色，保持至少 4.5:1 对比度；自定义的深色背景会计算同色系浅色文字。「样式」中可选从文字色进一步压暗的 0.5 px 细描边，默认关闭。
- 顶部/底部摘要横向，左右侧摘要竖向，默认宽度分别为 160 和 64 DIP。旧配置中的 178 DIP 默认值迁移为 160 DIP，其他自定义宽度保留。每 4 秒轮播账号，可调整为 2–60 秒；贴边摘要可只显示 5h、只显示 7d，或在两者间轮播。轮播完整个账号列表后切换周期；Pro 等没有 5h 限制的账号自动回退到 7d，已隐藏的周期也会回退到当前可显示的周期。旧的“最紧张/双条”配置迁移为双周期轮播。
- 悬停明细包含全部所选账号、平台、状态及订阅信息；订阅到期时间紧随会员类型。5h/7d 周期直接标在进度条左上角，重置倒计时标在右下角，不显示额外的周期标题和条下文案。倒计时以 `5d20h`、`1d5h`、`5h`、`4h3m` 格式显示；分钟段不显示秒，剩余不足一分钟时才显示 `59s` 等秒数。倒计时字号在“样式”页调整。
- “显示”页可开启并发数量，每个账号在进度条后显示一张独立小卡片，例如 `1/10`；贴边摘要只显示当前账号的一张。默认卡片宽度为 36 DIP，可在“样式”页设为任意正整数。数据取自 sub2api 0.2.8 的管理员账号列表，缺失字段不当作 0。配色与 sub2api 的并发徽标一致：空闲为 gray-100/600，使用中为 yellow-100/700，达到正数上限为 red-100/700；没有有效上限时不会把 `0/0` 判为满载。
- 重置次数取 OpenAI OAuth 的 `rate_limit_reset_credits.available_count`，最近到期时间取 `credits[].expires_at` 中最近的未过期值；两项各有独立的“显示”开关，默认开启。0 次或不支持的账号显示“无重置卡”并隐藏到期行；查询失败保留上次成功结果并提示错误。订阅类型和到期时间从服务端脱敏账号列表读取，每轮刷新同步；不会把令牌或本地账号到期时间当成订阅到期时间。
- 详情中的账号状态默认只显示文字；可在“显示”页启用状态开关。启用后，管理员登录且账号状态为可用或停用时显示开关，更新成功后同步本地状态，失败则保留原状态；其他状态及演示模式仍显示静态状态。头部只保留刷新按钮，鼠标离开后自动收起，账号多时可滚动。
- 详情分别尝试浮球四侧的位置，结合屏幕工作区裁剪后优先选与浮球不重叠的候选，避免屏幕角落的详情挡住浮球拖动。

## 焦点、透明度与字体

失焦且没有交互时，浮球默认不透明度为 65%。悬停、拖动或查看明细时变为 100%，变化约 140 毫秒。设置可以关闭淡化或将闲置不透明度设为 20–100%。设置与菜单本身保持不透明。浮球和明细使用 `focusable:false` 与 `showInactive()`，避免后台刷新、轮播和悬停抢占当前应用的输入焦点。

「样式」页统一管理状态颜色、界面字号（10–20 px）、粗细和 TTF 字体。导入只接受有效、20 MB 以内的 `.ttf`，复制到应用数据目录的固定文件名；窗口通过只暴露这一文件的本地 `quota-font` 协议加载。删除后回退到 Segoe UI/系统字体。浮球、明细、菜单和设置使用同一字体设置；窄进度条内的文字会按可用宽度收缩。
字号和粗细只作用于浮球以及设置页的浮球样式预览；设置页、托盘菜单和明细保持稳定的界面字号。托盘菜单使用 `pop-up-menu` 层级，等待 Electron 首次绘制、Vue 初始布局和外部事件监听就绪后，以非激活方式单次显示。菜单按图标所在显示器工作区定位，与任务栏和屏幕边缘保留 8 DIP 间距；展开更新确认时重新按同一图标计算位置。

设置窗口也等待首次绘制和 Vue 初始状态、布局就绪后再显示，首次加载期间合并重复打开请求，已经可见时只聚焦。关闭后缓存设置窗口，重开不重新加载页面；关闭或退出会取消尚未完成的打开请求，避免迟到回调重新显示窗口。登录与验证码按钮使用深绿底白字，禁用时为浅灰底深色文字，普通按钮样式不覆盖 Element Plus 的主按钮状态。

移除覆盖桌面的透明点击层，避免遮挡菜单按钮或遗漏任务栏、其他屏幕的点击。菜单打开期间启动独立 Electron utility process，通过 Koffi 注册 Windows 鼠标低级钩子和前台窗口切换事件；鼠标物理坐标在主进程转换为 DIP，菜单外的按下事件、前台窗口变化都会关闭菜单。钩子只观察并转发输入，菜单与更新确认仍直接接收正常点击。打开、操作和关闭菜单均不主动取得焦点，因此可以保留托盘“更多图标”面板；监听初始化失败时使用可聚焦菜单和失焦关闭作为回退。关闭、取消打开或退出时终止监听进程，Windows 自动移除钩子。退出后的迟到 IPC 会忽略已销毁的窗口。

## 登录、刷新与存储

登录使用邮箱和密码，支持 sub2api 0.2.8 的 `requires_2fa`、`temp_token` 和 `totp_code`。取得令牌后读取 `/auth/me` 确认管理员角色，再分页读取上游账号。密码不保存。访问令牌仅留在主进程内存；勾选记住登录时，刷新令牌使用 Electron `safeStorage` 的 Windows 用户加密能力落盘。

取数使用 0.2.8 的单账号额度接口，Claude OAuth/setup-token 请求被动数据，其他账号请求 active 数据；始终 `force=false`。OpenAI OAuth 还查询 `/admin/openai/accounts/{id}/quota` 获取重置卡及到期时间，两个显示开关只影响展示。刷新默认每 60 秒，可设 5–3600 秒或关闭。刷新合并、429 `Retry-After`、单账号错误缓存、会话切换与账号选择变更均在主进程处理。客户端不直接发起模型推理请求；服务器 active 查询可能依据自身冷却规则探测额度。

配置以 JSON 原子写入用户数据目录；加密令牌另存。TTF、别名、窗口位置和显示设置保留在本地。渲染进程启用沙箱与上下文隔离，只通过预加载脚本暴露有限命令，不接触管理员令牌、上游凭据或任意文件路径。

## 版本更新

安装版启动时立即检查 GitHub 正式 Release，之后默认每 10 分钟检查。间隔通过「刷新」页的「版本检查间隔」设置，单位为分钟，支持 1–10080 的整数，旧配置自动补入 10；保存后重设下一次检查计时，重启时加载已保存值。正在检查、下载或等待安装时不重复检查；开发预览不访问真实更新服务。发现新版显示托盘红点与更新确认，用户确认后下载，下载完成后再次确认重启安装。

## 验证边界

Vitest 覆盖额度映射、尺寸/工作区几何、别名、2FA、管理员校验、0.2.8 查询与限流。Playwright 通过实际 Electron 进程验证拖动、悬停、透明度、自绘菜单、设置、TTF、别名、贴边轮播和本地模拟服务器登录，并对开发版和打包版截图。回归新增多轮设置、隐藏、显示和刷新，以及 `--force-device-scale-factor=1.75` 下的持续移动、长按和静止期间不重复写窗口边界。computer-use 真实鼠标验证了设置后再次点击设置、后续点击隐藏；菜单通过隔离配置的托盘测试事件打开。当前设备两块屏幕的系统缩放均为 100%；Electron 175% 测试未改变系统缩放，物理 4K/175% 和混合 DPI 仍需用户环境验收。
